# Ubes_Portfolio

A modern, high-end engineering portfolio website built with Next.js (App Router), Tailwind CSS, GSAP ScrollTrigger, Lenis smooth scrolling, and Motion.

## 🚀 Tech Stack

- **Framework:** Next.js 16 (App Router) & React 19
- **Styling:** Tailwind CSS, PostCSS, Custom SVG Film Grain
- **Animations:** GSAP & ScrollTrigger, Lenis Smooth Scroll, Framer Motion (`motion/react`)
- **Typography:** Syne, Space Grotesk, JetBrains Mono
- **Icons:** Lucide React & Custom Brand SVGs

## ✨ Key Features

- **Editorial Dark Aesthetic:** High-contrast charcoal and paper white tones with vibrant orange accents and tactile film grain texture.
- **Dynamic Intro Experience:** Interactive 3D cover loader with audio synthesizer feedback and smooth entry transitions.
- **Dancing Letters Hero:** Typographic hero banner with animated character physics and live telemetry status.
- **Kinetic Stack Spread:** Multi-card kinetic scattering physics powered by Motion.
- **Deep Project Showcases:** Architectural project deep-dives with system metrics and tech stack tags.
- **Technical Skills Matrix:** Interactive domain matrix categorized across Core CS, Web, AI/ML, and DevOps.
- **Evolution Timeline & Certifications:** Engineering journey trajectory and verified credential badges.
- **Terminal Footprint:** Live-styled developer console showcasing repository metrics and engineering stats.

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## 📦 Building for Production

```bash
npm run build
npm run start
```
